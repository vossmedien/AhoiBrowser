# Local MV3 probe

Load this directory unpacked from the installed AhoiBrowser extension page. The
action popup visibly proves service-worker messaging, local extension storage,
platform information, active-tab access, and extension-action rendering.

This fixture is not Chrome Web Store evidence and is not a substitute for the
real signed-app MV3, update, removal, 1Password, or Bitwarden Phase-0 journeys.
It requests no host access and contains no remote code.
