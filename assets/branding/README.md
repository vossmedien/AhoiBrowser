# AhoiBrowser icon source

`ahoi-browser-icon-1024.png` is the canonical raster master for the native
AhoiBrowser application mark. It was generated specifically for this project
and then visually simplified for legibility at 16, 32, 128 and 1024 pixels.

The identity combines a maritime sail/browser-lens silhouette with two subtle
effervescent bubbles. It is intentionally original: no third-party wordmark,
packaging, mascot or existing browser logo is embedded in the artwork.

The Chromium overlay contains deterministic size derivatives for runtime theme
resources plus a compiled macOS `app.icns` and `Assets.car`. When the master is
replaced, regenerate every derivative from the same reviewed master so Dock,
Finder, Settings, helper apps and in-product surfaces cannot drift apart.
